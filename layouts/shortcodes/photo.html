{{/* PHOTO PAGE - a /photo page in the spirit of Robert Birming's (robertbirming.com/photo). (Oct 19, 2026) Pairs with custom.css section 120. Usage on the Micro.blog page at /photo/ : {{< photo >}} uses the "Photos" category {{< photo category="Photos" >}} any other category The newest post in the category is shown big, with its first photo, Toby's comment from the post as the caption, the date, and a "+N more in this post" link when the post holds several photos. Every older post becomes a square tile below, newest first, using its first photo, with a small stack badge when the post has more inside. Updates itself on every build. Rules: - Only Toby's own uploads count (cdn.uploads.micro.blog or the blog's /uploads/). Book and movie card posters are skipped, same as the home page thumbnails. - A post whose text says "Credit:" is someone else's photo (the Orion nebula post, Mar 2026) and is left out. - A post with no uploaded photo (the Instagram embed) is left out. - Alt text that is only a filename ("4261.jpg") or starts with Micro.blog's "Auto-generated description:" is cleaned up; empty alt falls back to the post title or date. - The "Last updated" line prints a date at build time; a tiny script turns it into "3 hours ago" style in the browser. Renders nothing if no post qualifies. */}} {{- $cat := .Get "category" | default "Photos" -}} {{- $posts := where (where .Site.RegularPages "Type" "post") "Params.categories" "intersect" (slice $cat) -}} {{- $shots := slice -}} {{- range $posts.ByDate.Reverse -}} {{- $p := . -}} {{- if not (in (lower $p.Content) "credit:") -}} {{- $posters := slice -}} {{- range findRE `(?s)(?:book|movie)-card-poster[^>]*>\s*]+src="[^"]+"` $p.Content -}} {{- $posters = $posters | append (htmlUnescape (replaceRE `(?s)^.*?]+src="([^"]+)".*$` "$1" .)) -}} {{- end -}} {{- $srcs := slice -}} {{- $alts := slice -}} {{- range findRE `]+>` $p.Content -}} {{- $tag := . -}} {{- $u := htmlUnescape (replaceRE `(?s)^.*?src="([^"]+)".*$` "$1" $tag) -}} {{- if and (or (in $u "cdn.uploads.micro.blog") (in $u "/uploads/")) (not (in $posters $u)) -}} {{- $a := "" -}} {{- with findRE `alt="[^"]*"` $tag 1 -}}{{- $a = htmlUnescape (replaceRE `^alt="(.*)"$` "$1" (index . 0)) -}}{{- end -}} {{- $a = replaceRE `^Auto-generated description:\s*` "" $a -}} {{- if findRE `(?i)^[\w.\-]+\.(jpe?g|png|webp|gif|heic)$` $a 1 -}}{{- $a = "" -}}{{- end -}} {{- $srcs = $srcs | append $u -}} {{- $alts = $alts | append $a -}} {{- end -}} {{- end -}} {{- if gt (len $srcs) 0 -}} {{- $title := trim $p.Title " \n\t" -}} {{- $alt := index $alts 0 -}} {{- if not $alt -}}{{- $alt = cond (ne $title "") $title (printf "Photo from %s" ($p.Date.Format "January 2, 2006")) -}}{{- end -}} {{- $shots = $shots | append (dict "page" $p "src" (index $srcs 0) "alt" $alt "n" (len $srcs) "title" $title) -}} {{- end -}} {{- end -}} {{- end -}} {{- if gt (len $shots) 0 -}} {{- $hero := index $shots 0 -}} {{- $hp := $hero.page -}} {{- $caption := partial "clean-summary.html" (dict "page" $hp) -}}

This is my /photo page: my newest shot, swapped out whenever I share a new one. Last updated {{ $hp.Date.Format "2 Jan 2006" }}.
